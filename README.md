# cli-task-manager

CLI-менеджер задач на Go с хранением данных в SQLite.

## Возможности

- просмотр списка задач;
- добавление задачи с заголовком и описанием;
- удаление задачи по ID.

## Требования

- [Go](https://go.dev/) 1.26+

## Установка

```bash
cd server
go mod download
```

## Использование

Все команды выполняются из каталога `server`:

```bash
cd server
```

### Список задач

```bash
go run . list
```

### Добавить задачу

```bash
go run . add "Заголовок" "Описание задачи"
```

### Удалить задачу

```bash
go run . delete 3
```

где `3` — ID задачи из вывода команды `list`.

### Сборка бинарника

```bash
go build -o taskManager .
./taskManager list
```

## Структура проекта

```
cli-task-manager/
├── server/
│   ├── main.go    # точка входа и CLI-команды
│   ├── task.go    # работа с задачами (CRUD)
│   ├── db.go      # инициализация базы данных
│   ├── go.mod
│   └── task.db    # локальная SQLite БД (создаётся автоматически)
└── README.md
```

## База данных

При первом запуске в каталоге `server` создаётся файл `task.db` с таблицей `tasks`:

| Поле    | Тип     | Описание        |
|---------|---------|-----------------|
| id      | INTEGER | первичный ключ  |
| title   | TEXT    | заголовок       |
| content | TEXT    | описание        |

Файл `task.db` не коммитится в репозиторий — это локальные данные.
